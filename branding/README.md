# Archivexus Branding

This directory contains the official visual identity of Archivexus.

## Assets

- `logo.svg` — Primary logo.
- `icon.svg` — Symbol only.
- `banner.svg` — Repository banner.
- `favicon.svg` — Browser icon.
- `social-preview.png` — GitHub/OpenGraph image.

## Design Principles

Archivexus represents:

- Memory
- Knowledge
- Connections
- Discovery
- Living worlds

Visual assets should prioritize simplicity, scalability and readability.

The logo should work in monochrome and at small sizes.
