# Archivexus Brand Guidelines

## Keywords

- Memory
- Knowledge
- Discovery
- Connection
- History
- Worldbuilding

## Personality

- Intelligent
- Elegant
- Timeless
- Minimal
- Trustworthy

## Avoid

- Generic fantasy clichés
- Overly ornate medieval fonts
- Excessive visual complexity
- AI/"cyber" aesthetics that overshadow readability

## Visual Direction

Archivexus should feel like an ancient archive enhanced by modern technology—not a video game logo.
