# Archivexus Vision

> **Every world has a memory. Archivexus preserves it.**

---

## What is Archivexus?

Archivexus is a knowledge layer for tabletop roleplaying worlds.

Built on top of Foundry VTT, it transforms isolated documents into a connected, living memory that grows alongside your campaign.

Actors, Journals, Scenes, Items, Organizations, Events and every other piece of your world become part of a single interconnected network of knowledge.

Archivexus does not replace Foundry.

It helps Foundry remember.

---

## Vision

Every campaign eventually becomes larger than anyone can remember.

Names are forgotten.

Relationships become unclear.

Events lose context.

Knowledge becomes fragmented.

The Game Master should never have to fight against their own documentation.

Archivexus exists to preserve the memory of a world.

The Game Master tells the story.

Archivexus remembers it.

---

## Core Principles

- Memory over Documentation
- Knowledge through Relationships
- A Single Source of Truth
- History is Part of the World
- Optional Structure
- Automation over Maintenance
- Transparency
- Extensible by Design

---

## Long-Term Goal

To become the memory layer for tabletop roleplaying.

Not by replacing existing tools.

But by connecting them.

---

## Guiding Question

Every new feature should answer one question.

> Does this help preserve the memory of the world?
