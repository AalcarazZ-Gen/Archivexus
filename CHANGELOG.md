- VIEW-001e (issue #70): the **"Everything connected" preset renders its depth-2 ring as collapsed, category-labelled clusters by default** (ADR-0007 point 6, mandatory; ADR-0014 Amendment A5) — a hub Node no longer floods the canvas on first use.
  - **`graph-clusters.ts`** (new, pure) — `buildClusteredTraversal(traversal, definitionsById)` partitions an "everything-connected" `TraversalResult` into the **direct ring** (depth 1, always expanded) and **clusters** over the depth-2 Nodes, each keyed by the `traversalCategory` of the Relationship that links it into the ring (fixed taxonomy order, `Other` last, shared `categoryLabel` → `"Affiliation (12)"`). A depth-2 Node lands in exactly one cluster (its first linking edge wins) so the collapsed canvas stays unambiguous. `buildClusteredGraphElements(traversal, clustered, expandedClusterIds)` turns that into Cytoscape elements: a collapsed cluster is one node + aggregate edges from its anchors; an expanded one is a compound parent box holding its members (`data.parent`), emitted parent-before-child for `cy.add()`.

New `filterTraversalForViewer(traversal, { isGM })` — applies the ADR-0003 viewer filter to a whole `TraversalResult` *before* clustering, so a collapsed cluster's count can never leak how many `hidden` Nodes it holds.
  - **`graph-popout-window.ts`** — when the preset is "Everything connected" and the graph is rooted, it clusters. Tap a collapsed cluster node → expands in place; **"Collapse clusters"** toolbar button (shown only while something is expanded) resets it; switching preset, re-rooting, "Whole graph", and the two context-menu re-root actions all clear the expansion state. Status line gains `· N/M clusters expanded`. Cluster nodes get their own dashed-box / solid-pill Cytoscape styling (`cytoscape-loader.ts`).
  - `index.ts` exports the new surfaces. **+11 unit tests (589 total, up from 578)**; `tsc` / `eslint` / `vitest` / `build:foundry-module` all clean (`archivexus.js` ~131KB → ~137KB). **Not yet live-verified:** the Cytoscape compound-node render + tap-to-expand, and the "Collapse clusters" button toggle.
