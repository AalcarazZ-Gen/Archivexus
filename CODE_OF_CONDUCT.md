# Code of Conduct

Archivexus adopts the Contributor Covenant Code of Conduct.

We are committed to providing a welcoming, respectful and inclusive environment for everyone.

Participants are expected to:

- Be respectful.
- Assume good intentions.
- Focus on constructive feedback.
- Help improve both the project and the community.

Unacceptable behavior includes:

- Harassment.
- Personal attacks.
- Discrimination.
- Bad faith contributions.

Project maintainers reserve the right to remove contributions that violate these principles.

For the full Contributor Covenant text, please visit:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/
